Branching Commands

These are some of the basic commands

Let's dive into some of the basic ones first! Got to start somewhere right?

Check out the table below for some useful commands

Command Description
git init Creates a new repository
git add Adds your changes to the staging area
git commit This is one of the most useful commands, to save your changes!
git status Tells you which branch you are on, and which files you have staged waiting to be committed and untracked files
git push For pushing your changes to the remote server

Let's dive into some basic Branch Commands

Check out the table below for some useful commands

Command Description
git branch List all local branches in the current repository
git branch -a List all branches (local and remote)
git branch -r List remote branches
git branch -vv List branches with more details
git branch -l List all branches (local)
git branch -m old_branch new_branch Rename a branch

Commit

A Commit is when you make changes and save your work

Tree

A Tree Object creates the relationship between files in a Git Repository

Tags

A Tag is a specific point in a repository's history as being important. For example, you might want to tag a release version of your project.
